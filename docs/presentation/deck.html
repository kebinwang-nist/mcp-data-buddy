What it is1:15–2:00

Narration1:15–2:00

mcp-data-buddy is a set of small servers built on the Model Context Protocol, or MCP. MCP is a standard way for AI assistants to use outside tools. Here, one server handles CDC data and another handles FDA data. A gateway sits in front and combines them. It connects to tools like Claude Desktop or VS Code, or to the project's own chat client.

What it can do2:00–3:00

Narration2:00–3:00

On the CDC side, the assistant can discover datasets by topic, such as vaccination coverage or smoking rates, and then query them. On the FDA side, it can look up drug adverse events, labeling, the NDC directory, the Orange Book, recalls and shortages. It also covers food recalls and food adverse events. Both sources are free, and an API key is only needed for higher FDA rate limits.

Optional AI check

A second model looks for names, street addresses and birth dates. If that check fails, the call is blocked by default.

In a recorded run on 23 Nov 2026, one shortage result had 86 phone numbers and 1 email redacted before the model saw it.

Privacy protection3:00–3:50

Narration3:00–3:50

Health data raises privacy concerns, so the gateway scans every request and response. It looks for Social Security numbers, emails, phone numbers, credit cards and IP addresses. It can block, redact or log what it finds. An optional second AI check also catches names, street addresses and birth dates. Privacy is part of the design, not an afterthought.

Are there any current shortages for lidocaine?
fda_list_datasets→fda_get_dataset×45 calls · 18 s

Yes. The FDA drug shortage database lists lidocaine as currently in shortage. It has 87 lidocaine entries, all marked "Current", last updated 19–20 Nov 2026.

  • Mostly injectable lidocaine: plain, with epinephrine, and premixed with dextrose.
  • From 10 manufacturers, led by Fresenius Kabi (32) and Hospira/Pfizer (26).
  • Hospira expects recovery of some products between March and September 2027.
Which CDC datasets cover respiratory viruses?
cdc_list_datasets×44 calls · 14 s

The CDC datasets on respiratory viruses fall into four groups.

  • vjzj-u7u8 NSSP Emergency Department Respiratory Daily, about 311,000 rows.
  • 4bc2-bbpq Provisional Percent of Deaths for COVID-19, Influenza, and RSV, weekly.
  • qeq7-f3ir RSV vaccination coverage and intent among adults, weekly.
  • cr56-k9wj Influenza A measurements from infected ferrets (NCIRD).

…and 30+ more. “I can query any of these datasets, for example to pull recent trends.”
